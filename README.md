## Projects

### Project 1 — Windows Authentication & Endpoint Investigation

Investigated a simulated Windows authentication sequence involving multiple
failed logons followed by a successful authentication.

The investigation included:

- Windows Security Event ID 4625 analysis
- Windows Security Event ID 4624 analysis
- Logon ID correlation
- Sysmon Event ID 1 process analysis
- PowerShell and Windows Command Shell activity
- Parent-child process analysis
- System discovery using `whoami`, `hostname` and `ipconfig`
- Evidence-based incident assessment
- MITRE ATT&CK technique mapping

**Tools:** Windows Event Viewer, PowerShell, Sysmon, Windows 11, VirtualBox
